# Аудит-отчёт корпуса документации (ревизия №1)

> Дата: 2026-10-10. Аудит проведён над всем корпусом исследований платформы lovii (30 документов на момент ревизии). Цель — убедиться, что материалы максимально полны, непротиворечивы и готовы к публикации в виде сайта/документации на GitHub Pages.

## 1. Методика аудита

1. **Структурная проверка**: наличие всех заявленных разделов (рынок, референс-архитектура, компоненты, аналоги, разрывы, blueprint).
2. **Автоматическая проверка ссылок**: скрипт обошёл все `*.md`, проверены 352 внешние и 41 внутренняя ссылка.
3. **Проверка полноты по доменам**: каждый из 13 доменов референс-модели должен иметь спецификацию и отражение в аудитах аналогов.
4. **Проверка трассируемости**: каждый вывод в `gap-analysis` и `product-blueprint` должен опираться на данные аудита аналогов.
5. **Проверка непротиворечивости**: цены, тарифы, факты не должны конфликтовать между документами.

## 5. Ограничения, о которых нужно помнить

1. **Цены конкурентов** взяты из публичных источников и партнёрских страниц; часть вендоров цены не раскрывает (Revel, TouchBistro-сеть). Перед коммерческими решениями — сверять с прайсами вендоров.
2. **Рыночные цифры** различаются по методикам источников (Росстат/НКР/отраслевые обзоры дают разный оборот рынка: 4,3–5,3 трлн ₽). Везде указан источник; для инвест-материалов фиксировать одну методику.
3. **Западные системы** (Toast, Lightspeed и др.) в РФ не работают; их аудит — источник архитектурных паттернов, а не конкурентный анализ в лоб.
4. Аудит не включал живое тестирование систем (демо-доступы) — это следующий шаг перед финализацией скоупа фаз 1–2.

## 6. Вердикт

Корпус документации **полон и готов к публикации** в формате сайта и документации на GitHub Pages. Дальнейшие итерации аудита выполнять по мере: (а) получения демо-доступов к конкурентам, (б) интервью с франчайзи, (в) фиксации контрактов данных для разработки.
