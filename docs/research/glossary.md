# Глоссарий

Термины, используемые в документации платформы. Группировка: бизнес, кухня и производство, склад и закупки, регулирование, доставка, лояльность, платформа.

## Бизнес и форматы

| Термин | Значение |
|---|---|
| **Общепит / HoReCa** | Отели, рестораны, кафе; в нашем контексте — предприятия общественного питания |
| **Дарк китчен (dark kitchen)** | Кухня, работающая только на доставку, без зала |
| **Фабрика-кухня** | Центральное производство, выпускающее полуфабрикаты/готовую еду для сети точек |
| **Франчайзер / УК** | Управляющая компания — владелец бренда и стандартов |
| **Франчайзи** | Партнёр, работающий под брендом по договору |
| **Паушальный взнос** | Разовый платёж за вход во франшизу |
| **Роялти** | Регулярный платёж франчайзеру, обычно % от выручки |
| **Средний чек** | Выручка / число чеков за период |
| **Фудкост (food cost)** | Себестоимость продуктов в % от выручки |
| **Лейбор кост (labor cost)** | ФОТ в % от выручки |
| **Стоп-лист** | Перечень позиций, временно снятых с продажи |

## Кухня и производство

| Термин | Значение |
|---|---|
| **ТТК** | Технико-технологическая карта блюда: состав, граммовки, потери при обработке, выход, способ приготовления |
| **Калькуляционная карта** | Расчёт себестоимости блюда по ТТК и закупочным ценам |
| **Нормы закладки** | Количество сырья на порцию с учётом потерь |
| **Полуфабрикат** | Заготовка, входящая в состав блюд; имеет собственную ТТК |
| **Акт производства / разбора** | Документ выпуска партии полуфабрикатов из сырья / разбора сырья |
| **Бракераж** | Контроль качества готовой продукции с записью в журнал |
| **Курс** | Подача (первое/второе/десерт) — порядок выноса блюд |
| **Станция / цех** | Рабочая зона кухни (горячий, холодный, гриль, бар) |
| **KDS** | Kitchen Display System — кухонный экран с заказами и таймингами |
| **Экспо (expo)** | Позиция/роль сборки и выдачи заказов |
| **Время тикета** | Время от приёма заказа до готовности |

## Склад и закупки

| Термин | Значение |
|---|---|
| **Автозаказ** | Автоматическое формирование заказа поставщику по прогнозу потребности |
| **ФИФО (FIFO)** | Метод списания: первым пришёл — первым списан |
| **Инвентаризация** | Пересчёт фактических остатков и сверка с учётными |
| **Слепая инвентаризация** | Пересчёт без отображения учётных остатков (антиподгонка) |
| **ЭДО** | Электронный документооборот (УПД, накладные с юр. значимостью) |
| **УПД** | Универсальный передаточный документ |
| **Партия** | Единица учёта товара с ценой и сроком годности конкретной поставки |
| **Прослеживаемость** | Возможность восстановить цепочку «партия → блюдо → чек» |

## Регулирование (РФ)

| Термин | Значение |
|---|---|
| **54-ФЗ** | Закон о применении контрольно-кассовой техники при расчётах |
| **ККТ** | Контрольно-кассовая техника (касса) из реестра ФНС |
| **ФН** | Фискальный накопитель внутри ККТ (на 15/36 мес) |
| **ФФД** | Формат фискальных документов; 1.2 — обязательная версия для маркировки |
| **ОФД** | Оператор фискальных данных — передаёт чеки в ФНС |
| **ТС ПИоТ** | Технические средства получения информации о товаре; обязательный модуль проверки кодов маркировки на кассе |
| **ЕГАИС** | Госсистема учёта оборота алкоголя |
| **Честный ЗНАК** | Госсистема цифровой маркировки товаров (молочка, вода и др.) |
| **Меркурий (ВетИС)** | Госсистема ветеринарной сертификации (мясо, рыба, молочка); гашение ВСД при приёмке |
| **ВСД** | Ветеринарный сопроводительный документ |
| **152-ФЗ** | Закон о персональных данных (согласия, хранение в РФ) |
| **ХАССП (HACCP)** | Система анализа рисков и критических контрольных точек пищевой безопасности |

## Заказы и доставка

| Термин | Значение |
|---|---|
| **Агрегатор** | Маркетплейс доставки (Яндекс Еда, Деливери, СберФуд) |
| **Первая сторона (1P)** | Прямые заказы через собственные каналы (сайт, приложение) |
| **Третья сторона (3P)** | Заказы через агрегаторы |
| **Зона доставки** | Территория, в которой точка доставляет заказы |
| **Слот** | Временное окно доставки/самовывоза |
| **Пакетирование** | Объединение нескольких заказов в один рейс курьера |
| **Обещание времени** | Гарантируемое гостю время доставки |
| **Киоск самообслуживания** | Терминал приёма заказа без кассира |
| **Облачная касса** | Арендованная ККТ в дата-центре для онлайн-платежей |

## Лояльность и гости

| Термин | Значение |
|---|---|
| **Профиль гостя** | Склейка данных гостя из всех каналов |
| **Бонусный счёт** | Баллы гостя, используемые как скидка |
| **Кэшбэк-механика** | Начисление % от чека баллами |
| **RFM** | Сегментация по давности (Recency), частоте (Frequency), деньгам (Money) |
| **NPS** | Net Promoter Score — индекс готовности рекомендовать |
| **Реактивация** | Возврат «спящих» гостей офферами |
| **Сервис-рекавери** | Отработка негативного отзыва компенсацией |

## Платформа

| Термин | Значение |
|---|---|
| **Тенант** | Изолированный клиент платформы (УК/франчайзи/точка) |
| **Мультитенантность** | Одна платформа — много изолированных клиентов |
| **Офлайн-первый** | Фронт работает без облака, данные синхронизируются позже |
| **Событийная шина** | Единый журнал событий системы, источник остатков и отчётов |
| **Вебхук** | Уведомление внешней системы о событии |
| **Драйвер ККТ** | Адаптер платформы к конкретной модели кассы |
