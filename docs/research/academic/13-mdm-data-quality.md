# Разбор 13. Качество данных и MDM в сетях: мастер-данные меню, гостей, поставщиков

> Академическая серия, выпуск 13. В сети из десятков точек ошибка в справочнике умножается на все точки. Управление мастер-данными (MDM) и качество данных — отдельная дисциплина внутри платформенного слоя.

## 1. Различение данных

| Класс | Определение | Примеры |
|---|---|---|
| **Мастер-данные (НСИ)** | Относительно стабильные справочные сущности, используемые всеми процессами | Меню и ТТК, ингредиенты, гости, поставщики, точки, сотрудники |
| **Транзакционные данные** | Факты деятельности | Заказы, чеки, движения склада |
| **Аналитические данные** | Производные витрины | Дашборды, индексы, бенчмарки |

Качество мастер-данных определяет качество всего остального: неверная ТТК портит фудкост, автозаказ и производство одновременно.

## 2. Модель качества данных

Классическая рамка Ванга и Стронга (1996) — качество как «соответствие данных требованиям использования», четыре группы измерений:

| Группа | Измерения |
|---|---|
| Внутреннее качество | точность, непротиворечивость, полнота, уникальность |
| Контекстуальное качество | релевантность, достаточность, актуальность |
| Репрезентационное качество | интерпретируемость, понятность, согласованность форматов |
| Доступностное качество | доступность, защищённость |

## 3. Домены мастер-данных платформы и владение

| Домен | Владелец (кто редактирует) | Правила наследования |
|---|---|---|
| Меню и ТТК | УК (эталон), точки (локальные позиции при разрешении) | Версионированный шаблон: раскат → локальное переопределение цен/стопов |
| Ингредиенты | УК + товароведы точек | Единые единицы измерения и категории — глобально |
| Гости | Точки сбора + платформенная склейка | Золотая запись гостя: слияние по телефонам с ручным разбором конфликтов |
| Поставщики | УК (допуски), точки (локальные) | Матрица «кто у кого закупает» как атрибут тенанта |
| Точки и устройства | УК | Иерархия тенантов ([`../components/12-data-model.md`](../components/12-data-model.md)) |

## 4. Ключевые механизмы

1. **Золотая запись (golden record)** — каноническая версия гостя/поставщика при дублях; разрешение сущностей (entity resolution) по телефонам и реквизитам.
2. **Версионирование шаблонов** — изменение меню УК распространяется контролируемо, с подтверждением франчайзи и откатом ([`../components/09-franchise-network.md`](../components/09-franchise-network.md)).
3. **Профилирование данных** — регулярные автоматические проверки: дубли ТТК, отрицательные остатки без актов, позиции без ТТК, гости без согласий.
4. **Журнал изменений справочников** — кто и когда изменил цену/состав/право; основа доверия франчайзи к УК.

## 5. Цена плохих данных (почему это приоритет)

- Ошибка граммовки ТТК в 10% на популярной позиции → систематическое искажение фудкоста на всех точках сети.
- Дубли гостя → неверные сегменты и двойные бонусы.
- Разные единицы измерения у точек (кг/упаковка) → ошибки автозаказа и приёмки.
