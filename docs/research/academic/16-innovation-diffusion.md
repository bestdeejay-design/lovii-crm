# Разбор 16. Диффузия инноваций в сетях: как раскатывать изменения по франчайзи

> **Статус: ревизия №2 по итогам аудита корпуса · 10.10.2026.** Числовые факты сопровождаются ссылками; канонические перечисления — в «Модели данных», §0.

> Академическая серия, выпуск 16. Обновление меню, новые стандарты, переход на модуль платформы — это внедрение инноваций в социальную систему. Теория диффузии Роджерса объясняет, почему «разослали всем одновременно» не работает и как раскатывать правильно.

## 1. Теория диффузии инноваций (Роджерс, 1962/2003)

**Диффузия** — процесс, в котором инновация распространяется по каналам во времени среди членов социальной системы. Скорость принятия определяется пятью воспринимаемыми свойствами инновации:

| Свойство | Определение | Вопрос для раскатки в сети |
|---|---|---|
| **Относительное преимущество** | Насколько новшество лучше прежнего | Видит ли франчайзи выгоду в цифрах? |
| **Совместимость** | Соответствие ценностям, опыту, процессам | Ложится ли на текущие процессы точки? |
| **Сложность** | Трудность понимания/использования | Сколько времени на переобучение? |
| **Пробуемость** | Можно ли попробовать в малом | Есть ли пилотный режим? |
| **Наблюдаемость** | Видны ли результаты другим | Покажем ли успешные точки сети? |

## 2. Категории принимающих (нормальное распределение)

| Категория | Доля | Роль в сети |
|---|---|---|
| Новаторы | ~2,5% | Точки-энтузиасты: первыми берут эксперименты |
| Ранние последователи | ~13,5% | Успешные франчайзи-лидеры — «чемпионы» раскатки |
| Раннее большинство | ~34% | Ждут доказательств от лидеров |
| Позднее большинство | ~34% | Принимают под давлением нормы и стандарта |
| отстающие | ~16% | Только через обязательность стандарта |

Практический вывод: **не продавать инновацию всем сразу** — сначала новаторы и чемпионы, затем массовая раскатка с опорой на их результаты (эффект «пропасти» Мура для ранних сегментов актуален и для внутренних внедрений).

## 3. Механика раскатки в франшизной сети

1. **Пилот на собственных и лояльных точках** (пробуемость): нововведение обкатывается в контролируемых условиях.
2. **Упаковка наблюдаемости**: кейс пилота с метриками (выручка, скорость, индекс стандарта) в кабинет франчайзи.
3. **Версионирование и раскат шаблона**: обновление распространяется как версия шаблона точки с подтверждением франчайзи и откатом ([`../components/09-franchise-network.md`](../components/09-franchise-network.md)).
4. **Каналы влияния**: встречи франчайзи, чаты сети, рейтинги точек — социальное доказательство сильнее приказа.
5. **Обязательность по порогу**: когда доля принявших высока, для отстающих нововведение закрепляется в стандарте с датой вступления.

## 4. Управление изменениями (рамка)

Восемь шагов Коттера (1996) сжимаются для сети до: ощущение срочности (зачем сейчас) → коалиция чемпионов → видение результата → быстрые победы пилота → закрепление в стандарте и обучении.

## 5. Определитель «ситуация → решение»

| Ситуация | Решение |
|---|---|
| Сеть сопротивляется новому меню | проверить наблюдаемость: есть ли успешный кейс в цифрах? |
| Половина точек игнорирует обновление | стадия позднего большинства: подключать стандарт и аудит, а не уговоры |
| Нововведение «сломало» одну точку | откат версии шаблона + разбор в пилотной группе |

## 6. Соответствие платформе

Шаблоны точек и раскат версий ([`../components/09-franchise-network.md`](../components/09-franchise-network.md)); платформа как канал наблюдаемости — дашборды УК ([`../components/08-finance-analytics.md`](../components/08-finance-analytics.md)).
