# Разбор 7. Терминология операционного менеджмента: ограничения и очереди

> Академическая серия, выпуск 7. Кухня, выдача и доставка — это производственно-сервисные системы, описываемые теорией ограничений и теорией массового обслуживания. Точные термины позволяют проектировать нормативы времени и загрузку смен, а не гадать.

## 1. Теория ограничений (Голдратт)

Классика: Э. Голдратт, «Цель» (1984). Ключевые понятия:

| Термин | Определение |
|---|---|
| **Ограничение (узкое место, bottleneck)** | Ресурс, мощность которого меньше потребности системы; определяет пропускную способность всей системы |
| **Пропускная способность (throughput)** | Скорость генерации денег через продажи (для кухни — заказов в час через самую узкую станцию) |
| **Такт** | Требуемый ритм выпуска под спрос |
| **Запасы и операционные расходы** | Два других показателя системы по Голдратту (наряду с пропускной способностью) |
| **Пять шагов фокусировки** | 1) найти ограничение → 2) максимально использовать его → 3) подчинить всё остальное ограничению → 4) расширить ограничение → 5) вернуться к шагу 1 (не допуская инерции) |

**Применение на кухне:** станция гриля, ожидающая 8 минут на пике, и есть ограничение; расширение (вторая станция, заготовки заранее) даёт больше, чем ускорение любой другой станции. Платформа даёт данные для поиска ограничения: время тикетов по станциям ([`../components/03-kitchen-kds.md`](../components/03-kitchen-kds.md)).

## 2. Теория массового обслуживания: базовые понятия

| Термин | Определение |
|---|---|
| **Поток заявок** | Поступление заказов; характеризуется интенсивностью λ и вариативностью |
| **Интенсивность обслуживания** | μ — скорость обработки одним каналом (станцией/кассой/курьером) |
| **Коэффициент загрузки (utilization)** | ρ = λ/μ; при ρ → 1 время ожидания растёт нелинейно |
| **Закон Литтла** | Среднее число заявок в системе = интенсивность поступления × среднее время в системе (L = λW) |
| **Очередь и дисциплина** | Ожидание обработки; дисциплины: FIFO, приоритетная, пакетная |
| **Пакетирование (batching)** | Обработка группы заявок одним рейсом/проходом (доставка: 2–3 заказа на курьера) |

**Ключевой управленческий факт:** время ожидания взрывается при загрузке выше ~0,8–0,85 (следствие аппроксимации Кингмана для G/G/1). Поэтому «загрузить поваров на 100%» и «обслуживать без ожидания» — взаимоисключающие цели; планирование смен строится на целевой загрузке, а не на максимуме.

## 3. Сервисные операции в общепите

| Термин | Определение |
|---|---|
| **Производительность услуги** | Баланс эффективности и качества (при полной самоавтоматизации падает воспринимаемое качество — классическая дилемма сервисных операций) |
| **Декупаж процессов** | Разделение операций «фронт/бэк» (кухня отделена от зала; доставка отделена от зала) — способ переноса вариабельности в бэк |
| **Скорость выдачи** | Время от готовности до вручения; отдельно кухня (готовка) и логистика (дорога) |
| **Обещание времени** | Контракт с гостем; строится из нормативов кухни + упаковки + маршрута |

## 4. Определитель «ситуация → термин»

| Ситуация | Правильно |
|---|---|
| «Кухня не справляется» | идентифицировать ограничение по временам тикетов, а не «всё плохо» |
| Очереди при ρ ≈ 1 | структурная проблема загрузки, а не «ленивый персонал» |
| Два заказа одним курьером | пакетирование; требует соблюдения слотов |
| «Ускорим всех» | ошибка: ускорение не-ограничения не меняет throughput |
