# Разбор 2. Юнит-экономика точки общепита

> **Статус: ревизия №2 по итогам аудита корпуса · 10.10.2026.** Числовые факты сопровождаются ссылками; канонические перечисления — в «Модели данных», §0.

> Академическая серия, выпуск 2. Юнит-экономика — математический скелет франшизного предложения: если модель одной точки не сходится, масштабирование умножает убытки, а не прибыль.

## 1. Понятие и структура модели

**Юнит-экономика точки** — разложение финансового результата одной точки на управляемые множители:

```
Прибыль = Выручка − Переменные затраты − Постоянные затраты
Выручка = Σ по каналам (Трафик × Средний чек)
Трафик = Вместимость × Оборачиваемость × Загрузка (для зала)
       = Пропускная способность кухни × Загрузка (для доставки/фастфуда)
```

Переменные затраты считаются в % от выручки (фудкост, часть ФОТ, эквайринг, упаковка, комиссия агрегатора), постоянные — в рублях (аренда, оклады, коммуналка, маркетинг-база).

## 2. Каноничная модель расходов (бенчмарки)

| Статья | Доля выручки | Комментарий |
|---|---|---|
| Фудкост | 12–40% (ориентир 25%) | кофейни ниже, мясо/суши выше [1](https://blog.quickresto.ru/chto-takoe-fudkost) |
| ФОТ | 25–35% | вместе с фудкостом — прайм-кост до ~70% [2](https://www.finoko.ru/zatraty-restorana/) |
| Аренда + ЖКХ | 10–15% | выше — сигнал о неверной локации |
| Маркетинг | 2–5% | +сетевой маркетинговый сбор во франшизе |
| Эквайринг | 1–2,7% | СБП заметно дешевле классического эквайринга |
| Прочие операционные | 5–10% | списания, ремонт, связь, охрана |
| Роялти (во франшизе) | 2–6% | см. [Разбор 5](05-franchising-economics.md) |
| **Чистая прибыль** | **5–15%** | рынок РФ в среднем ~8% |

**Правило «30/30/30/10»** — мнемоника отраслевой структуры: ФОТ ~30% / продукты ~30% / прочие операционные ~30% (внутри них аренда и ЖКХ — ориентир 10–15% выручки из таблицы выше) / прибыль ~10% [3](https://restoplace.cc/blog/na-chem-zarabativaet-restoran). Популярная расшифровка «аренда = 30%» ошибочна: она вдвое превышает собственный бенчмарк аренды и не сходится с фудкостом 25–30%.

## 3. Чувствительность: где живут деньги

- **1 п.п. фудкоста** при выручке 5 млн ₽/мес = 50 тыс ₽/мес чистой прибыли (600 тыс ₽/год) — при рентабельности 8% это ±12,5% прибыли точки (50 000 / 400 000).
- **Комиссия агрегатора 16,67–29,17% без НДС (≡ 20–35% с НДС)** делает заказы через него низко- или отрицательно-маржинальными: экономика прямого канала — главный довод строить свою витрину (каноническая вилка — [`../components/02-order-channels.md`](../components/02-order-channels.md)).
- **ФОТ при спаде трафика** не сжимается мгновенно: планирование смен под прогноз загрузки — основной рычаг.
- **Аренда в % от выручки** — лучшая страховка на старте (переговорная позиция франчайзи).

## 4. Юнит-экономика доставки (отдельная модель)

```
Вклад заказа = Средний чек
             − Фудкост
             − Упаковка
             − Стоимость доставки (курьер × время)
             − Комиссия канала (0% свой / 16,67–29,17% агрегатор)
             − Эквайринг
```

Порог безубыточности доставки определяется минимальным чеком, зонами и плотностью заказов (пакетирование 2–3 заказов на рейс снижает стоимость доставки на заказ). Поэтому в платформе зоны, минимальный чек и обещание времени — не «фичи», а **параметры экономической модели**.

## 5. Инвестиционная модель франчайзи

| Блок | Состав |
|---|---|
| Инвестиции (CAPEX) | Ремонт, оборудование, вывеска, паушальный взнос, депозиты, оборотный капитал на 2–3 месяца |
| Прогноз выручки | По бенчмаркам сети: выручка сопоставимых точек × локальные поправочные коэффициенты |
| Операционная модель | Структура из §2 + роялти + маркетинговый сбор |
| Выходные показатели | Срок окупаемости (цель 12–24 мес для фастфуда), IRR, запас прочности |

Честная финмодель строится на **фактических данных действующих точек сети** (потому платформа обязана собирать их автоматически) — это же защита франчайзера от претензий о «завышенных обещаниях».

## 6. Метрики, которые должна считать платформа

- Выручка/маржа по каналам (зал, самовывоз, своя доставка, каждый агрегатор) с учётом комиссий.
- Фудкост план/факт и отклонения по причинам.
- ФОТ на смену против прогноза выручки.
- Точка безубыточности и запас прочности по точке (авто-расчёт из фактических статей).
- Юнит-экономика доставки: вклад на заказ, стоимость рейса, доля пакетированных рейсов.
