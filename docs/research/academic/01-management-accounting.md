# Разбор 1. Терминология управленческого учёта в общепите

> **Статус: ревизия №2 по итогам аудита корпуса · 10.10.2026.** Числовые факты сопровождаются ссылками; канонические перечисления — в «Модели данных», §0.

> Академическая серия, выпуск 1. Цель — единый язык финансов в документах, переговорах с франчайзи и проектировании финансового модуля платформы. Разбор построен по схеме: понятие → строгое определение → способы измерения → правила применения.

## 1. Две системы учёта: почему управленческий — отдельно

- **Финансовый (бухгалтерский) учёт** — внешняя отчётность по стандартам (РСБУ/МСФО): точность, ретроспектива, регулятор.
- **Управленческий учёт** — внутренние данные для решений: скорость, детализация по центрам ответственности (точка, цех, канал), план против факта. Классическая база — Хорнгрен и др. «Управленческий учёт».

В общепите разрыв особенно важен: кассовые данные появляются секунда в секунду, а бухгалтерия — раз в месяц. **Вывод для платформы:** витрина владельца строится на управленческом контуре, 1С — экспорт для регулятора.

## 2. Классификации затрат (базовые различения)

| Основание | Пары | Пример из общепита |
|---|---|---|
| Реакция на объём | постоянные / переменные | аренда / продукты |
| Относимость к продукту | прямые / косвенные | лосось в ролле / уборка зала |
| Управляемость на точке | контролируемые / неконтролируемые | списания / ставка эквайринга |
| Отношение к выручке | в % от выручки / фиксированные | роялти 4% / оклад бухгалтера |

**Прайм-кост (prime cost)** — сумма фудкоста и лейбор-коста; главный контролируемый агрегат: в общепите доходит до 70% выручки [1](https://www.finoko.ru/zatraty-restorana/). Управлять прибылью = управлять прайм-костом.

## 3. Структура управленческого P&L точки (канон)

| Строка | Определение | Бенчмарк |
|---|---|---|
| Выручка (брутто) | Все продажи до скидок | — |
| Скидки и комплименты | Минус: акции, сервис-рекавери, питание персонала | 2–5% |
| Выручка (нетто) | База для всех процентов | — |
| Себестоимость продуктов (фудкост) | Списание по ТТК и актам | кофейни 12–16%; рестораны 25–40%; ориентир 25% [2](https://blog.quickresto.ru/chto-takoe-fudkost) |
| **Валовая прибыль** | Нетто − фудкост | — |
| ФОТ (лейбор-кост) | Зарплаты, взносы, питание, форма | 25–35% |
| Аренда и коммунальные | — | 10–15% (входит в «прочие операционные» канонической расшифровки правила «30/30/30/10» — см. [Разбор 2](02-unit-economics.md)) [3](https://restoplace.cc/blog/na-chem-zarabativaet-restoran) |
| Маркетинг, эквайринг, доставка, ремонт, списания, прочее | Операционные | 10–20% |
| **Операционная прибыль / EBITDA** | Прибыль до амортизации, процентов, налогов | 10–20% у здоровых точек |
| Амортизация, проценты, налоги | — | — |
| **Чистая прибыль** | Итог владельца | 5–15% (рыночная рентабельность общепита РФ ~8% и снижается) |

## 4. Фудкост: строгая терминология

- **Фудкост** — отношение себестоимости реализованных продуктов к выручке от них, в % [3](https://restoplace.cc/blog/na-chem-zarabativaet-restoran).
- **Теоретический фудкост** — расчёт по ТТК и действующим ценам (сколько должно списаться).
- **Фактический фудкост** — по реальному расходу (начальный остаток + приход − конечный остаток, делённое на продажи).
- **Отклонение (variance)** — факт минус теория; источник диагностических сигналов: воровство, ошибки ТТК, порча, нарушения граммовок.
- **Наценка ≠ маржа** (частая ошибка): наценка = (цена − себестоимость)/себестоимость; маржа = (цена − себестоимость)/цена. Фудкост 25% ⇔ маржа 75% ⇔ наценка 300%.

## 5. Термины операционной эффективности

| Термин | Определение |
|---|---|
| Средний чек | Выручка / число чеков |
| Оборачиваемость стола | Число посадок за стол за период |
| Выручка на место/на м² | Плотность монетизации зала |
| Выручка на человеко-час | Производительность персонала |
| Доля доставки/самовывоза | Канальный микс выручки |
| Сезонность | Коэффициенты отклонения по дням/месяцам от среднего |

## 6. Метрики инвестиций и возврата

| Термин | Определение |
|---|---|
| CAPEX / OPEX | Капитальные / операционные затраты |
| Точка безубыточности | Выручка, при которой маржинальный доход покрывает постоянные затраты |
| Запас прочности | Отношение фактической выручки к точке безубыточности |
| Срок окупаемости (простой и дисконтированный) | Период возврата инвестиций |
| EBITDA margin | EBITDA / выручка; стандарт сравнения точек |

## 7. Определитель «ситуация → термин»

| Ситуация | Правильно |
|---|---|
| «Сколько зарабатывает точка» без вычета аренды | операционная прибыль / EBITDA (уточнить) |
| Сравнение точек разного размера | выручка на м², EBITDA margin — не абсолютная выручка |
| Рост цен в чеках без роста гостей | инфляционный рост; смотреть средний чек и трафик отдельно |
| «Прибыль» франчайзи до роялти | маржа до сетевых платежей (важно при продаже франшизы) |

**Антипаттерны:** называть валовую прибыль «чистой»; сравнивать фудкост форматов с разной структурой (кофейня против мясного ресторана) без оговорки; управлять «затратами вообще» вместо прайм-коста.
