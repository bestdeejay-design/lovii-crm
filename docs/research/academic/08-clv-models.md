# Разбор 8. Модели ценности гостя: от RFM к вероятностным моделям

> **Статус: ревизия №2 по итогам аудита корпуса · 10.10.2026.** Числовые факты сопровождаются ссылками; канонические перечисления — в «Модели данных», §0.

> Академическая серия, выпуск 8. «Кто наш ценный гость и сколько он принесёт» — вопрос, на который аналитический контур лояльности должен отвечать не интуицией, а моделью.

## 1. Определение и виды оценки

**Ценность гостя (CLV/LTV)** — дисконтированная прибыль, которую гость принесёт за всё время отношений.

| Вид | Суть | Когда применяется |
|---|---|---|
| **Историческая** | Прибыль по уже совершённым покупкам | Отчёты и сегментация «по факту» |
| **Прогнозная** | Математическое ожидание будущей прибыли | Кампании, бюджеты реактивации, оценка каналов |

Базовая упрощённая формула:

```
Прогнозный CLV ≈ Средний чек × Частота покупок × «Время жизни» × Маржа
```

## 2. Сегментация: от когорт к RFM

- **Когортный анализ** — поведение групп гостей по месяцу первого заказа (удержание, частота) — базовая диагностика продукта.
- **Модель Парето в клиентской базе** — эмпирическая закономерность «20% гостей дают ~80% выручки» (в общепите выражена ярко).
- **RFM-сегментация** — ранжирование по давности (Recency), частоте (Frequency), деньгам (Monetary); практична, прозрачна, объяснима.

## 3. Вероятностные модели (академический стандарт)

Для транзакционных покупок без подписки (наш случай — еда) классика стохастического моделирования:

| Модель | Авторы | Что моделирует |
|---|---|---|
| **Парето/НБД** | Шмитлейн и др. (1987) | Частоту повторных покупок живых клиентов + вероятность оттока |
| **Гамма-Гамма** | Фадер, Хардти, Ли (2005) | Среднюю сумму покупки при условии количества покупок |
| **БГ/НБД** | Фадер, Хардти, Ли (2005) | Вычислительно удобная версия Парето/НБД — фактический стандарт практики |
| **БГ/ББ** | Фадер, Хардти, Шанг (2010) | **Не**контрактные отношения с дискретными транзакциями — гостевые визиты ресторанов, наш основной случай |
| **сБГ (sBG)** | Фадер, Хардти (2007) | Договорные (контрактные) отношения с оттоком в дату продления — подписки, корпоративный кейтеринг |

Модели дают: вероятность «живости» гостя, ожидаемое число будущих покупок, прогнозную частоту — и, в связке с маржой, прогнозный CLV на гостя. Входные данные — история заказов из единой базы платформы (поэтому склейка гостя через каналы — не «фича», а источник данных модели).

## 4. Практическая связка для платформы

1. **Сегментация и триггеры:** реактивация «спящих» (порог определяется моделью, а не произвольным числом дней).
2. **Бюджет возврата:** допустимая стоимость реактивации = доля прогнозного CLV.
3. **Оценка каналов:** сравнение агрегаторов и собственных каналов по CLV приведённых гостей (а не по первому чеку) — экономический аргумент в пользу прямого канала.
4. **Программа лояльности:** бонусные ставки дифференцируются по сегментам ценности (дорогим гостям — сервис, а не скидка).

## 5. Ограничения

- Модели требуют достаточно длинной истории (для новых точек — сначала когорты и RFM).
- Сезонность и локальные события искажают «время жизни» — нужны поправки.
- Прогноз чувствителен к качеству склейки гостя (дубли завышают частоту).
