# Разбор 14. Бережливое производство на кухне: 5S, потери, визуальный менеджмент

> Академическая серия, выпуск 14. Производственная система Тойоты адаптируется к кухне почти без натяжки: кухня — производственный цех с тактом, запасами и переналадками. Разбор даёт словарь и приёмы для операционных стандартов франшизы.

## 1. Основание: производственная система Тойоты

Классика: Тайити Оно и «Тойота: методы бережливого производства» (Вумек, Джонс, 1990 — «Машина, которая изменила мир»). Центральные понятия:

| Термин | Определение |
|---|---|
| **Муда (потери)** | Любая деятельность, потребляющая ресурсы, но не создающая ценности для гостя |
| **Мура (неравномерность)** | Колебания загрузки: то простой, то аврал — источник потерь и ошибок |
| **Мури (перегрузка)** | Требования к людям и оборудованию сверх разумного |
| **Кайдзен** | Непрерывное малое улучшение силами самих исполнителей |
| **Андон** | Сигнал о проблеме, останавливающий/привлекающий внимание немедленно |

## 2. Семь потерь — перевод на кухню

| Потеря | Ресторанный пример |
|---|---|
| Перепроизводство | Заготовки сверх прогноза → списания |
| Ожидание | Повар ждёт выдачу, курьер ждёт заказ |
| Транспортировка | Лишние переносы между холодильниками и станциями |
| Излишняя обработка | Повторные операции (двойная переупаковка, пересчёт) |
| Запасы | Избыточные остатки «на всякий случай» (замороженные деньги + просрочка) |
| Движения | Плохая эргономика станции |
| Дефекты | Возвраты и переготовка из-за ошибок заказа |

## 3. Метод 5S для станций

| Шаг | Содержание на кухне |
|---|---|
| **Сортировка (Сейри)** | Убрать со станции всё, что не нужно для текущей смены |
| **Соблюдение порядка (Сейтон)** | Каждому инвентарю/заготовке — своё место с маркировкой |
| **Содержание в чистоте (Сейсо)** | Уборка как часть смены, а не «после смены» |
| **Стандартизация (Сейкецу)** | Единый стандарт станций во всех точках сети (фото-эталон) |
| **Совершенствование (Сицуке)** | Дисциплина исполнения и чек-листы |

## 4. Визуальный менеджмент

- **Этикетки сроков** и маркировка заготовок (цвет дня — «цветовой код смены»).
- **КДС как андон**: просроченный тикет подсвечивается — сигнал без крика.
- **Фото подачи** на экране — эталон без слов.
- **Доска показателей смены**: время тикетов, стоп-лист, заготовки.

## 5. Встраивание в платформу и стандарты франшизы

- Чек-листы открытия/закрытия станции включают 5S-пункты ([`../components/10-compliance-safety.md`](../components/10-compliance-safety.md)).
- План заготовок по прогнозу продаж сокращает потерю «перепроизводство» ([`../components/04-inventory-procurement.md`](../components/04-inventory-procurement.md)).
- KDS-тайминги и алерты — цифровой андон ([`../components/03-kitchen-kds.md`](../components/03-kitchen-kds.md)).
- Стандарт станции с фото — часть шаблона точки УК ([`../components/09-franchise-network.md`](../components/09-franchise-network.md)).

## 6. Определитель «ситуация → термин»

| Ситуация | Правильно |
|---|---|
| Заготовки списываются каждый день | потеря перепроизводства; лечить прогнозом заготовок, а не «запретом списаний» |
| Повара простаивают, потом аврал | мура — неравномерность; выравнивание загрузки и планирование смен |
| Поиск инвентаря занимает минуты | нарушение 5S (шаг 2) |
