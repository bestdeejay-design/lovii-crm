# Разбор 6. Терминология пищевой безопасности: ХАССП и прослеживаемость

> Академическая серия, выпуск 6. Пищевая безопасность — юридически обязательная и репутационно критичная часть франшизы общепита. Разбор фиксирует академическую и нормативную базу терминов комплаенс-модуля.

## 1. Нормативный фундамент

- **Кодекс Алиментариус (Codex Alimentarius)** — свод стандартов ФАО/ВОЗ (с 1963 г.); «Общие принципы гигиены пищевых продуктов» (CXC 1-1969) — международный эталон, в который включены принципы ХАССП.
- **ТР ТС 021/2011 «О безопасности пищевой продукции»** — техрегламент ЕАЭС, обязывающий предприятия общепита внедрить принципы ХАССП в производственные процессы; отсутствие — основание для претензий Роспотребнадзора.
- **СанПиН 2.3/2.4.3590-20** — санитарные требования к организации общественного питания в РФ.

## 2. ХАССП: строгие определения

| Термин | Определение (по Кодексу Алиментариус) |
|---|---|
| **ХАССП (HACCP)** | Система анализа опасностей и критических контрольных точек: профилактическая, а не реактивная модель безопасности |
| **Опасность (hazard)** | Биологический, химический или физический агент в пище, способный причинить вред здоровью |
| **Анализ опасностей** | Процесс выявления опасностей и оценки их значимости |
| **Критическая контрольная точка (ККТ/ССP)** | Этап, на котором контроль существенен для предотвращения/устранения опасности или снижения её до приемлемого уровня |
| **Критический предел** | Измеримое значение, отделяющее приемлемое от неприемлемого (например, температура хранения) |
| **Мониторинг** | Плановые измерения/наблюдения в ККТ |
| **Корректирующее действие** | Действие при выходе за критический предел |
| **Верификация** | Проверка, что система ХАССП работает как задумано |
| **Документирование** | Журналы и записи — доказательства функционирования системы |

**12 шагов внедрения** (5 подготовительных + 7 принципов): команда → описание продукта → назначение по использованию → блок-схема процесса → подтверждение схемы на месте → анализ опасностей → определение ККТ → критические пределы → мониторинг → корректирующие действия → верификация → документация.

## 3. ККТ против обязательных предварительных программ

Академически важно различать:

- **Предварительные программы (PRP)** — базовая санитарная среда: уборка, гигиена персонала, борьба с вредителями, температурный режим складов, мойка. Работают «везде и всегда».
- **ККТ** — только там, где без контроля конкретной точки опасность не устраняется процессом (например, температура доготовки/охлаждения, разогрев).

Ошибка практики — превращать в ККТ всё подряд; корректная система — узкие ККТ поверх крепких PRP.

## 4. Прослеживаемость и смежные термины

| Термин | Определение |
|---|---|
| **Прослеживаемость (traceability)** | Возможность восстановить историю партии «на шаг назад и на шаг вперёд» (принцип Кодекса: от кого получили → кому передали) |
| **Партия/лот** | Совокупность единиц продукции, произведённых/полученных в идентичных условиях |
| **Ротация (FEFO/FIFO)** | Первым истекает — первым используется / первым пришёл — первым использован |
| **Срок годности** | Период, в течение которого продукция сохраняет безопасность и качество |
| **Бракераж** | Процедура оценки готовой продукции перед выпуском с записью в журнал |
| **Перекрёстное загрязнение** | Перенос опасностей с сырья/поверхностей на готовую продукцию |
| **Температурная опасная зона** | Диапазон, в котором активно размножаются патогены (ориентир +5…+60 °C) |
| **Товарное соседство** | Правила раздельного хранения разных групп продуктов |

## 5. Связь с платформой

Комплаенс-модуль ([`../components/10-compliance-safety.md`](../components/10-compliance-safety.md)) реализует: ХАССП-чек-листы поверх партий склада (прослеживаемость следует из событийной модели остатков), температурные журналы, этикетки заготовок со сроками, бракераж, карту рисков сети для УК. Меркурий/ЧЗ/ЕГАИС — государственный слой той же прослеживаемости.

## 6. Определитель «ситуация → термин»

| Ситуация | Правильно |
|---|---|
| Журнал температур холодильника | мониторинг ККТ/предварительной программы, не «просто журнал» |
| Партия молока с истекающим сроком | ротация по FEFO, алерт платформы |
| Жалоба гостя с подозрением на отравление | запуск процедуры прослеживаемости партии |
| Уборка по графику | предварительная программа (не ККТ) |
