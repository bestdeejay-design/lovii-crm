# Компонент 04. Склад, техкарты, фудкост, закупки и поставщики

> Домен D4. Самый «денежный» домен после кассы: 30–40% выручки уходит в продукты. 1–2 процентных пункта фудкоста = месяцы прибыли микробизнеса.

## 1. Техкарты (ТТК) — фундамент всего

- Состав блюда: ингредиенты, граммовки, потери при холодной/горяней обработке, выход порции; калькуляционная карта с себестоимостью.
- Модификаторы влияют на расход («двойной сыр» = +30 г сыра в списание).
- Замены и аналоги: нет ингредиента — система подставляет аналог и пересчитывает [1](https://sb-1c.ru/blog/post/kakuyu-konfiguraciyu-1s-vybrat-dlya-kafe-i-restorana).
- Сезонные рецепты, разные нормы закладки на разные периоды, аллергены и пищевая ценность (БЖУ) для меню [2](https://alexrovich.ru/info/articles/1s-obshchepit-osobennosti-vnedreniya/).
- Полуфабрикаты — рекурсивные ТТК; акты проработки при вводе новинки.
- Готовые библиотеки рецептов ускоряют онбординг: у Saby Presto встроенный каталог на 3000 рецептов [3](https://saby-sbis.ru/blog/programmy-dlya-avtomatizacii-obshchepita-podborka-dlya-kafe-i-restorana) — обязательный приём для франшизы.

## 2. Складской учёт

### Операции
- Приёмка (по накладной/ЭДО, со сверкой цены и количества), возврат поставщику.
- Перемещения между складами (основной склад → кухня → бар) и между точками.
- Списание: продажа по ТТК, порча, проработка, питание персонала, недостача.
- Инвентаризация: полная/частичная/слепая, с телефона и по зонам хранения; расчёт отклонений и причин.
- Сроки годности и ротация (ФИФО), контроль просрочки.

### Модель данных
- **Остаток — проекция журнала движений**: каждая операция = событие (кто, когда, чем подтверждено). Это даёт аудитируемость («почему −3 кг?») и корректную историю себестоимости.
- Себестоимость блюда пересчитывается после каждой поставки (скользящая/ФИФО по партиям) — так сделано в Poster [4](https://hf.ru/services/poster_pos).

## 3. Закупки и поставщики

- Справочник поставщиков с прайс-листами, графиками поставок, условиями оплаты; контроль закупочных цен (сигнал при росте цены сверх порога; блокировка приёмки с ценой выше согласованной — практика iiko [5](https://cabus.ru/iiko)).
- **Автозаказ**: система считает потребность по прогнозу продаж + остаткам + нормам закладки и формирует заказ поставщику на подтверждение закупщику (есть в iiko [6](https://journal.sovcombank.ru/biznesu/programma-iiko-aiko-dlya-restoranov-opisanie-preimuschestva), Quick Resto [7](https://prowizard.store/company/articles/vybiraem_programmnoe_obespechenie_ucheta_dlya_obshchepita/), 1С:Общепит [2](https://alexrovich.ru/info/articles/1s-obshchepit-osobennosti-vnedreniya/)).
- Приёмка с планшета/телефона прямо на складе, напоминания о неподтверждённых поставках.
- ЭДО (УПД) с поставщиками: юридически значимые документы без бумаги; приёмка маркированного товара только через ЭДО.
- Тендер/сравнение цен по позициям у нескольких поставщиков; матрица «что у кого покупать».

## 4. Фудкост-контроль

- Плановая себестоимость блюда (по ТТК и последним ценам) против фактической (по фактическим списаниям).
- Отклонения: теоретический расход против факта инвентаризации → поиск воровства, перерасхода, ошибок ТТК.
- ABC-анализ меню: маржа × популярность → решение по меню и закупкам (в iiko входит в базовую аналитику [8](https://www.restohub.pro/avtomatizaciya-restorana-iiko-2026)).
- Целевые фудкосты по категориям и по точке; алерты при выходе за порог.

## 6. Метрики домена

- Фудкост % (план/факт) по точке и категории; отклонение факт-инвентаризации.
- Оборачиваемость запасов в днях; доля списаний/просрочки в выручке.
- Точность автозаказа (дефицит в смену / излишки к списанию).
- Динамика закупочных цен по топ-30 позиций.

## 7. Требования к реализации для lovii

1. Журнал движений как единственный источник остатков; каждый документ подписывается исполнителем и привязан к устройству.
2. Библиотека ТТК франшизы: УК публикует эталонные техкарты, точки наследуют с локальными переопределениями цен.
3. Автозаказ по прогнозу (первая версия — скользящее среднее + день недели; дальше — градиентный бустинг/сезонность) с ручным подтверждением.
4. Мобильная приёмка и «слепая» инвентаризация с телефона; фото накладных.
5. Выгрузка в 1С/бухгалтерию — обязательно (рынок ожидает связку с 1С [1](https://sb-1c.ru/blog/post/kakuyu-konfiguraciyu-1s-vybrat-dlya-kafe-i-restorana)).
