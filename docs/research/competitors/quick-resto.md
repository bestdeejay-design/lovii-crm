## 2. Сильные стороны

1. Сбалансированный «полный цикл» для малых форматов: зал, кухня, склад, доставка, гостевое приложение — в одной подписке.
2. Хорошая автоматизация закупок с прогнозом спроса [1](https://prowizard.store/company/articles/vybiraem_programmnoe_obespechenie_ucheta_dlya_obshchepita/).
3. Гостевое приложение «из коробки» — редкость в МСБ-сегменте.

## 3. Слабые стороны

1. **Кассовый модуль работает только на iOS** (по данным обзоров) [5](https://vc.ru/services/2492795-programmy-avtomatizatsii-obshchepita-top-14-luchshikh-pos-sistem) — зависимость от платформы и стоимости железа.
2. ЕГАИС и ЭДО — через внешние решения, не нативно [4](https://multi-bit.com/avt_iiko/avtomatizatsiya-restorana).
3. Частая критика — **слабая служба поддержки** [6](https://prowizard.store/company/articles/vybiraem_programmnoe_obespechenie_ucheta_dlya_obshchepita/).
4. Меньше интеграций и глубины, чем у «тяжёлых» систем [2](https://iikoservice.ru/blog/chto-vybrat-dlya-avtomatizaczii-predpriyatiya/).

## 4. Выводы для lovii

- Quick Resto подтверждает спрос на «всё в одном» по ~5 тыс ₽/мес — прямой ценовой конкурент нашего стартового тарифа.
- Уязвимые места, по которым нужно бить: нативные госсистемы из коробки (ЕГАИС/ЧЗ/Меркурий/ЭДО), поддержка 24/7, кроссплатформенность кассы (не привязываться к iOS/Windows).
- Гостевое приложение у МСБ-системы — обязательный элемент нашего предложения: отзывы, баллы и история прямо в телефоне гостя.
