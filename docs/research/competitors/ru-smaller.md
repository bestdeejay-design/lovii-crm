# Аудит аналогов: второй эшелон РФ — Tillypad, Fusion POS, Yuma, Эвотор-решения

## 1. Tillypad

**Позиция:** модульная система от небольших кафе до крупных сетей; заявлено 15 000 заведений [1](https://multi-bit.com/avt_iiko/avtomatizatsiya-restorana).

- Модульная сборка «из разных частей»: учёт продаж и склада, кассовые операции, бронирование, отдельный модуль ЕГАИС, интеграция с 1С [1](https://multi-bit.com/avt_iiko/avtomatizatsiya-restorana).
- Интеграция со складским решением StoreHouse; мобильные приложения персонала и гостей; программы лояльности и акций; аналитика продаж и финансов [2](https://vc.ru/services/2492795-programmy-avtomatizatsii-obshchepita-top-14-luchshikh-pos-sistem).
- Распространение через дилеров; по оценкам обзоров, кастомные доработки дилеров усложняют обслуживание и ограничивают выбор подрядчика [1](https://multi-bit.com/avt_iiko/avtomatizatsiya-restorana).

**Вывод:** классическая «дилерская» модель — антипаттерн для франшизы, которой нужна масштабируемость без локальных интеграторов. Мы продаём и внедряем напрямую + партнёрский канал как дополнение.

## 2. Fusion POS

**Позиция:** облачное решение для ресторана, кафе, магазина, кальянной; модель «0 ₽/мес за ПО» с монетизацией вокруг [3](https://fusionpos.ru/).

- Касса на планшете/ПК с поддержкой 54-ФЗ, склад с контролем остатков, техкарты с авторасчётом себестоимости, CRM с бонусной программой и картами лояльности [3](https://fusionpos.ru/).
- Приложение руководителя: онлайн-выручка по точкам, заказы, остатки, кассовые операции, контроль смен и отчёты по сотрудникам, push-уведомления о важных событиях (крупные заказы, критические остатки, открытие/закрытие смен) [3](https://fusionpos.ru/).
- Права доступа по ролям (товаровед/маркетолог/бухгалтер) [3](https://fusionpos.ru/).
- Ограничения: эквайринг только Сбер; жалобы на ошибки с маркированным товаром [4](https://a2is.ru/catalog/programmy-dlya-kafe-i-restoranov/pos-fusion).

**Вывод:** модель «бесплатный софт + эквайринг/сервисы» — важное ценовое давление снизу. Наш бесплатный вход должен давать больше: склад+ТТК+госсистемы, а не только кассу.

## 3. Yuma

**Позиция:** система автоматизации с акцентом на доставку и dark kitchen: сайт и приложение в фирменном стиле с отправкой онлайн-заказов сразу в кассу, приложение курьеров [5](https://picktech.ru/catalog/food-delivery-software/).

**Вывод:** нишевый игрок подтверждает ценность связки «белая витрина + касса + курьер» — это наш базовый пакет для франшизы доставки.

## 4. Эвотор-экосистема и смарт-терминалы

Смарт-терминалы (Эвотор, MSPOS, aQsi) — дешёвое железо для микроточек с магазинами приложений; интеграции с ними (в т.ч. у Quick Resto) обязательны для охвата «островков» и кофеен [2](https://vc.ru/services/2492795-programmy-avtomatizatsii-obshchepita-top-14-luchshikh-pos-sistem).

## 5. Общий вывод по второму эшелону

| Система | Ниша | Что забираем как урок |
|---|---|---|
| Tillypad | сети через дилеров | модульность без дилерской зависимости |
| Fusion POS | микро с бесплатным входом | монетизация вокруг бесплатной кассы, пуш-алерты владельцу |
